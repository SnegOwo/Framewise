Framewise is a local time tracker for Windows that follows the app in focus. This guide covers installation, projects, focus tools, reports, privacy and the small details.

Windows 10/11 No account Offline by default MIT

Getting started

Framewise 1.0 is available for Windows 10/11 from GitHub Releases. Choose the installer for a normal per-user install, or the portable zip to keep everything in one folder.

Same app, two ways to install. The installer registers Framewise for the current user. The portable zip contains framewise.exe, framewise.portable and a readme; keep the folder together and data stays in data/.

First run

  1. Run framewise.exe. A short welcome setup asks how you want Framewise to work — theme, goal counting, notifications, launch at login and Adobe apps. Scan the PC or choose the Adobe .exe files manually. Use Skip — use defaults if you prefer.
  2. Framewise opens the dashboard and sits in the tray.
  3. Open the project chip in the hero and pick a project, or type a new name.
  4. When the project is created, choose its focus tools from a template or the apps already saved in Framewise. Skip if you want to decide later.
  5. Work in an Adobe app. Time is credited to the selected project automatically.
  6. Click the tray icon once for the mini timer, or double-click for the full app.

Requirements

System

Windows 10 or 11, x64. WebView2 is already present on current Windows installs.

Network

None by default. The optional monthly update check is the only request, and it is off unless enabled.

Storage

One SQLite file plus the WebView2 profile, inside data/ in the portable folder.

Close

Closing the window leaves the tracker in the tray. Quit from the tray menu when you are done.

Projects & focus tools

A project is a name, an optional client and a colour. Select one in the hero, the dock or the tray. Adobe time is always attributed to the active project; other apps become part of that project once you add them as tools.

Create a project inline

Open the project field on the dashboard and type a name. If nothing matches, Framewise offers Create “your name”. Press Enter to create and select it without leaving the dashboard. The same fallback exists in the dock search.

Choose focus tools

When you create a project, Framewise immediately asks which apps count. Start from a Montage, YouTube video, Motion graphics or Photo edit template, or pick from apps already saved in Framewise. Use Skip for now if you are not sure; you can change the list later from the project page.

Not sure what you are working on? Choose No project in the project picker, dock or tray. Framewise keeps tracking overall time without assigning it to client work. Adobe sessions also stay unassigned.

When a project is done, open its row menu and choose Finish project. It moves to the Finished section, keeps all of its logged time, and disappears from the active picker, dock and tray. Open it from Finished and choose Reopen project if you need it again.

In Focus tools on the project page, use Templates, Add .exe, or quick-add an app already tracked by that project. Photoshop, Premiere, a browser, a screenshot tool — anything you consider real work for that project.

On tool

The current app is in this project's tool list. It counts as focused time.

Off tool

The app is still tracked, but counted as other time for this project.

Focus percentage is selected time ÷ (selected + other time). The project detail separates the two app lists, so a browser detour is visible rather than hidden. Projects with no tools show no focus bubble and keep non-Adobe time unassigned.

How tracking works

Every 1.5 seconds Framewise samples the foreground executable. It records the executable name and a time interval, never window titles, keystrokes or file contents.

Attribution rules

  • Adobe apps credit the active project. No project means unassigned.
  • Focus tools credit the project and are marked selected.
  • Other apps on a project with tools credit the project and are marked other.
  • No tools keeps non-Adobe time unassigned, as in earlier versions.
  • Framewise itself is never credited. While its window is in focus, the most recently used real app stays tracked.
  • Ignored apps are never tracked.

Pauses, idle and sleep

Idle, lock, sleep and hibernation stop the clock. Idle time is cut back to the last real input, so idle minutes are never billed. A sleep gap is not bridged with phantom time. Sessions split automatically at midnight and when the app, project or focus state changes. Opening Framewise does not create a gap — its own window is never counted, so the last real app keeps the session open.

Dashboard

The dashboard answers one question first: where did today go?

  • Hero sentence. Today's total and the active project. The project chip is editable.
  • Status card. Current app, live timer, and the green/red focus bubble when the project has tools.
  • Timeline. One track per app with session pills and a now cursor. Click an app name to inspect it.
  • Goals. Daily or weekly targets. By default only selected focus tools count; projects without tools count in full. Completion plays the optional time-bloom reward.
  • Heatmap. A year of activity. Click a day to open its sessions.

Reports & export

Pick a range — this week, last week, this month, 30 days, this year or custom — and optionally one project. The report shows total time, daily activity, apps and goals. Export the same data as CSV, JSON or Markdown from the export menu.

Reports are generated from the local database. There is no cloud sync, no email and no account.

Sessions

Sessions are grouped by day with sticky headings. Reassign a session's project inline, edit its app or time, delete it on hover, or add a manual session from the dock. Manual sessions use the project's current focus tools to decide whether they count as selected.

Mini timer

Single-click the tray icon to open the mini near the tray. Unpinned it behaves like a popover and closes when it loses focus. Pin keeps it open, then drag it from the body.

  • Drag the bottom-right corner to resize from 150 × 64 to 640 × 420.
  • Below 280 × 108 it becomes a time-only clock; controls fade in on hover.
  • Pin and size are remembered between sessions.

The Adobe scan checks Program Files, ProgramData, the Adobe folders in your user profile, the Windows registry and every fixed drive. It finds multiple installed versions and ignores helper executables, so only the main apps are added.

Privacy & data

Framewise stores executable names and time intervals in a local SQLite file in WAL mode, flushed every 15 seconds and checkpointed on quit. It never reads window titles, keystrokes, clipboard content or file contents. App inspection resolves a path locally, on demand, and never sends it anywhere.

The app is offline by default. If you enable Monthly update check during setup or in Settings, it asks GitHub for release metadata once every 30 days. No project data or identifiers are sent. The portable build does not use the in-app updater.

In the portable build, everything lives in data/ beside the exe. Nothing is written to AppData. Delete the folder to remove every trace. Use Settings → Backup before moving machines.

Build from source

Requirements: Node.js 20+, Rust with the MSVC toolchain, WebView2.

npm install
npm run tauri dev

Checks:

npm run check
npm run build
npm run audit:offline
cargo test --lib
cargo check

Build the portable folder with npm run build:portable, or the NSIS installer with npx tauri build. Outputs go to release/ and src-tauri/target/release/bundle/.

FAQ

Where is my data?

Portable: data/framewise.sqlite3 beside the exe. Installed builds use the app data folder. Settings → About shows the exact active path.

Why is my browser time not on a project?

The project has no focus tools yet. Open the project, add the browser as a tool, and new time will be credited as selected (green) or other (red).

Does Framewise work offline?

Yes. The app is offline by default. If you opt into the monthly update check, it fetches only GitHub release metadata. The website is separate.

Which time counts toward a goal?

By default, only selected focus tools count. If you open a project with 100 minutes but only 10 minutes are in its tools, the goal gets 10 minutes. Turn Count only focus time off in Settings to count all tracked project time instead. Projects without tools always count in full.

Is there an installer?

Yes. Use the installer from GitHub Releases, or the portable zip if you want no install.

Troubleshooting

The mini timer disappears

It is unpinned. Click Pin to keep it open while you work.

Nothing is tracking

Check that the app is not in the ignore list, that the session is not paused, and that Windows is not idle or locked. Ignored apps are never recorded.

The focus bubble is always red

The apps you use are not in the project's tool list. Add them from the project detail page, or quick-add them from the app list.

The app will not start from a removable drive

The portable folder needs write access for data/ and the WebView2 profile. Move it somewhere writable.

I moved the portable folder

Keep data/ with the exe. Moving the whole folder is fine; moving only the exe loses the local data.

Still stuck? Open an issue on GitHub. For a security report, use private vulnerability reporting instead.
